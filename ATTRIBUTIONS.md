# HBPlus Asset & Library Attributions

This document lists all third-party libraries, icon packages, typography assets, and media utilized within the **HBPlus** Cross-Platform Workspace Application, along with their respective open-source licensing.

---

### 1. Icons & Vector Assets
- **Lucide Icons & Phosphor React Native**
  - **Source:** [https://lucide.dev](https://lucide.dev) & [https://phosphoricons.com](https://phosphoricons.com)
  - **License:** MIT License
  - **Usage:** Executive interface vector icons across navigation, action triggers, module tiles, and status indicators. Zero emoji used in UI.

- **Google Identity Vector**
  - **Source:** Google Sign-In Branding Guidelines
  - **Usage:** Authentic 4-color vector glyph on OAuth authentication action button.

---

### 2. Typography & Fonts
- **Plus Jakarta Sans**
  - **Designer:** Tokotype (Gumpita Rahayu)
  - **License:** SIL Open Font License, Version 1.1 (OFL)
  - **Usage:** Headings, Display, and Brand Titles.

- **Inter**
  - **Designer:** Rasmus Andersson
  - **License:** SIL Open Font License, Version 1.1 (OFL)
  - **Usage:** Primary body text, labels, form controls, and UI descriptions.

- **JetBrains Mono**
  - **Designer:** JetBrains
  - **License:** SIL Open Font License, Version 1.1 (OFL)
  - **Usage:** Tabular numerals, currency figures, timers, timestamps, and identification codes.
